# Kazmi Portfolio

Personal research portfolio built with HTML, CSS, and vanilla JavaScript.

## Run locally
Open index.html, or run `python -m http.server 8000` in this folder and visit http://localhost:8000.

## Deploy on Vercel
Import this repository. Framework preset: Other. No build command is needed. Output directory: `.`.

## Edit
- index.html: profile, education, policy perspectives, and social links
- app.js: publications, research projects, experience, and interactions
- style.css: base responsive layout
- cyber.css: green-and-black theme, background imagery, and motion
- assets/: optimized AI-generated conceptual artwork

The CV, email address, and phone number are excluded from this repository by the owner's request. Social-profile links remain. The live Sites deployment is maintained separately.

No API keys, build dependencies, or backend services are required. Google Fonts loads externally with system-font fallbacks. Concept images are illustrative, not photographs of completed projects.
